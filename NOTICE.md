# NOTICE

This project, **Grit**, is a modified version of [openGym](https://github.com/DuarteSantos8/openGym) originally created by Duarte Santos.

### Modifications made:
- Project renamed to Grit
- Rebranding (icons, splash screens, titles)
- Added dedicated Personal Records (PR) tracking system
- Automatic smart PR detection on workout sets
- Integrated manual PR manager
- Custom APK build configuration for Android distribution
- GitHub Actions integration for automated releases
- Additional exercises translated to Spanish
